# 【最美家庭】周晓宇、陆燕红家庭：医法并肩共战疫

> 更新时间：2026-09-17 (UTC+8)

近日，由省妇联在全省范围内开展的“江苏省抗疫最美家庭”名单揭晓，经广泛寻找、层层推荐、集中公示、综合把关，最终确定200户“江苏省抗疫最美家庭”。我院医务部主任周晓宇、感染性疾病科副主任医师赵华两个家庭光荣上榜。

今天为大家讲述江苏省抗疫最美家庭——周晓宇、陆燕红家庭互相扶持、共同抗疫的故事。

“穿上白大褂，就要守好初心，切实履行好医生的职责！”这是南通大学附属医院呼吸内科主任医师周晓宇内心始终不变的职业信念。“我们法院人要在疫情防控工作中贡献我们的力量！”这是陆燕红在南通市港闸区人民法院疫情防控部署会议上铿锵有力的发言。“父母奋斗在抗疫一线，无暇顾及我，虽有不能团聚的遗憾，但我支持他们！”女儿周子涵从心底里由衷地敬佩父母。

**医者仁心，忘我奉献**

1996年，周晓宇来到南通大学附属医院工作，“大医精诚、以宏慈善”的院训便根植于他的从医理念中。周晓宇长期奋战在医疗一线，治病救人与钻研学习成为他日常工作生活中两条不变的路线。

今年疫情发生后，南通大学附属医院发热门诊接诊患者1200余人，留院观察250余人，确诊新冠肺炎患者1名，疑似3名，成功救治南通市首例新冠肺炎重型患者。在救治该新冠肺炎重型患者过程中，作为通大附院新冠肺炎防控工作领导小组办公室负责人、通大附院新冠肺炎医疗救治专家组成员、省疫情防控定点收治医院联络人的周晓宇常驻救治一线，组织院内救治专家组制订诊疗方案，在患者住院诊疗的15天里，先后组织会诊15次，其中省级远程会诊2次、市级会诊1次，院内救治专家组会诊12次，通过积极救治，患者于2月17日治愈出院。南通大学附属医院作为江苏省省级孕产妇危急重症救治指导中心和新生儿危急重症救治中心，承担着孕产妇和儿童新冠肺炎收治职责，先后收治紧急转诊的2名有密切接触史的临产妇和1名疑似婴儿，周晓宇根据医院的安排，第一时间组织协调医务部、护理部、感染办、妇产科、感染性疾病科、麻醉手术科、儿内科等科室进行MDT，讨论制订了孕妇治疗方案、孕妇转运流程、院感防护措施、产后护理、新生儿救治等方案，确保了母婴安全和健康。
**柔情关爱，司法为民**

作为基层法院院长，陆燕红肩负着南通市港闸区人民法院全院防疫工作指挥、领导工作。春节前，她提前部署全院防疫物资采购事宜，节日期间要求做好疫情期间诉讼事项告知工作，上班后妥善处理外来人员管控问题。在得知湖北宜昌猇亭区法院、葛洲坝法院身处疫情防控重点区域，防疫物资十分紧缺时，陆燕红第一时间发起募捐倡议，多渠道筹备一次性口罩2600只、医用一次性手套2500副、消毒洗手液170瓶、额温枪等各类防疫物资及时寄往湖北。

根据南通市港闸区区委要求，港闸法院选派40多名干警下沉企业协助防疫工作，陆燕红经常深入基层一线指导干警驻企防疫工作。陆燕红还狠抓执法办案主业，要求干警采取电话、微信、网络的形式开展诉讼执行活动，通过南通中院开发的支云庭审系统及其他方式积极开展审判执行工作，港闸法院的审执工作达到同期的70%左右，确保人民群众维护合法权益的诉讼权利不受疫情耽搁。
**相互支持，共筑“疫线”**

陆燕红深知丈夫奋战抗疫一线的艰辛与不易，也希望节日期间家人团聚、多陪伴寒假回家的女儿，但是面对突如其来的疫情，她在投入工作的同时，默默地给丈夫加油鼓劲，全力支持其冲锋在前，因为她深知周晓宇作为医者的情怀与担当。女儿周子涵从小就习惯了父母的忙碌，为了不影响父母参与疫情防控工作，她主动搬到亲戚家居住、生活和学习，让父母全身心地去参加防疫工作。“为大家，我愿意暂时舍弃小家！”女儿内心不舍，但又非常坚毅。因疫情影响，女儿周子涵这学期没有到校，在家上网课，顺利完成本学期课程。医生治病救人，法官治理社会矛盾，虽然是不同的职业，但周晓宇和陆燕红夫妻二人都在用自己的专业知识，守护着人们的健康和社会的和谐，他们知道责任在肩，必须努力奋斗，国家需要，更应携手并肩。
